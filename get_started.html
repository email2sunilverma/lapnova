Welcome to LapNova

LapNova is a comprehensive Flutter application designed to provide a seamless mobile computing experience. Whether you're building for iOS, Android, or web, LapNova offers a robust foundation with modern architecture and best practices built-in.

🚀 Modern Architecture

Built with Clean Architecture and BLoC pattern for scalable applications

📱 Cross-Platform

Deploy to iOS, Android, Web, Windows, Linux, and macOS

⚡ Performance

Optimized for speed with native performance on all platforms

Prerequisites

Before you begin, ensure you have the following installed:

Flutter SDK

Version 3.0.0 or higher

Download Flutter

Dart SDK

Included with Flutter

Automatically installed when you install Flutter

Git

Version 2.0 or higher

Download Git

IDE or Editor

Android Studio, VS Code, or IntelliJ IDEA

With Flutter and Dart plugins installed

Verify Installation

Run the following command to check your setup:

flutter doctor

This command checks your environment and displays a report of the status of your Flutter installation.

Installation

1

Clone the Repository

git clone https://github.com/yourusername/lapnova.git
cd lapnova
2

Get Dependencies

Install all required Flutter packages

flutter pub get
3

Build Code Generation

Generate necessary code files (if applicable)

flutter pub run build_runner build --delete-conflicting-outputs
4

Verify Installation

Check if everything is set up correctly

flutter pub get && flutter analyze

Configuration & Setup

Environment Variables

Create a .env file in the root directory with your configuration:

API_URL=your_api_url
API_KEY=your_api_key
DEBUG_MODE=true

Android Setup

  1. Navigate to the android directory
  2. Update local.properties with your SDK path if needed
  3. Run flutter pub get to sync Android dependencies

iOS Setup

  1. Navigate to the ios directory
  2. Run pod install to install dependencies
  3. Update deployment target if necessary in Xcode

Web Setup

For web platform support, ensure you have the web enablement flag:

flutter config --enable-web

Running Your First Build

1

List Connected Devices

flutter devices
2

Run Development Version

For Android (default device):

flutter run

Or specify a device:

flutter run -d device_id
3

Run in Release Mode

flutter run --release
4

Run on Web (Beta)

flutter run -d chrome
💡 Tip: Use flutter run with hot reload for faster development. Press R in the console to hot reload and Q to quit.
